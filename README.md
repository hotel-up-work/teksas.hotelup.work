# Готель «Техас»

Live site: https://teksas.hotelup.work

## About
Готель «Техас» надає послуги проживання у Кам'янці-Подільському, розташований за адресою просп. Грушевського, 27. За джерельним описом можливе поселення до 60 гостей, це можливість розміщення (guest capacity), а не кількість номерів чи категорій, які наразі не підтверджені. Готель підходить як для індивідуальних гостей і пар, так і для груп: туристичних, спортивних, робочих чи приватних компаній.

## Amenities
- Проживання з можливістю поселення до 60 осіб
- Сауна / баня на дровах (деталі та місткість уточнюються)
- Оренда альтанок (кількість, місткість і ціна не підтверджені)
